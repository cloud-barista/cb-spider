Stateless Mode

What's different in Stateless Mode

  • No ConnectionName is registered or selected. Every call supplies ProviderName + CSP-native CredentialInfo/RegionInfo inline.
  • No IID mapping is persisted to the MetaDB. The SystemId returned is always the raw CSP-native resource ID.
  • This server only ever runs one mode at a time; the badge in the top bar shows which one.
